# Live Sport Tracker

Application de suivi de scores et de calendriers sportifs développée en Python avec Streamlit.

## Fonctionnalités

- Récupération en temps réel des matchs de la Ligue des Champions via l'API Football-Data.org.
- Interface web interactive avec Streamlit.
- Navigation par jour (passés et futurs) pour consulter les scores et les matchs à venir.

## Prérequis

- Python 3.10 ou supérieur
- Une clé d'API gratuite sur [football-data.org](https://www.football-data.org/)
